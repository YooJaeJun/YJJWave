# YJJWave 기획서 — 물량 맞다이

> 한 줄: **수천~수만 마리 병사를 미친 듯이 쏟아부어, 끝없이 밀려오는 괴물 물결과 정면으로 맞다이 뜨는 디펜스.**
> 참고작: Here Comes the Horde (물량 전투의 쾌감). 그림·이름·UI는 따라 하지 않고 YJJ 식(냥코·졸라맨풍 멍충 병사)으로 간다.

## 1. 핵심 재미

| 재미 | 어떻게 |
|---|---|
| **물량의 쾌감** | 화면을 꽉 채운 아군 vs 적군. 숫자가 4천 VS 1천에서 2만 VS 2만으로 불어난다 |
| **부딪히는 순간** | 두 물결이 한가운데서 만나 서로 밀어내고, 피와 시체가 바닥에 계속 쌓인다 (안 지워짐) |
| **무한 성장** | 건물 레벨 + PoE식 거대한 특성 성좌 + 스펠. "이번엔 궁수 몰빵", "졸병 무한 생산" 같은 빌드가 갈린다 |
| **밀고 밀리는 전선** | 전선이 화면 위에서 눈에 보이게 오간다. 밀리면 성벽까지 오고, 밀어붙이면 적 둥지까지 간다 |

## 2. 한 판의 흐름

1. 왼쪽은 우리 **진지**(성벽 + 건설 칸), 오른쪽 끝에서 괴물이 끝없이 몰려온다.
2. 금화로 진지 칸에 **병영**을 짓는다. 병영은 몇 초마다 병사 무리를 내보낸다 (자동 전진·자동 전투).
3. 시간이 흐르면 **물결 레벨**이 오른다 (레벨마다 타이머). 레벨이 오를수록 적이 많아지고 세진다. 5레벨마다 **보스**.
4. 적을 잡으면 **금화**(건설·강화)와 **영혼**(특성 성좌)이 들어온다.
5. 성벽 체력이 0이 되면 패배. 기록 = 버틴 레벨·처치 수. (목표 레벨 도달 시 승리는 추후)

## 3. 성장 요소 (무수히)

### 3-1. 병영 (건물) — 금화
- 진지 칸 24개(6줄×4칸)에 자유롭게 짓는다. 같은 병영을 여러 개 지어 물량을 늘린다.
- 병영 레벨업: 한 번에 나오는 수 증가, 생산 주기 단축, 병사 능력치 증가. 비용은 레벨마다 배로.
- 종류 (처음 4종)
  | 병영 | 병사 | 역할 |
  |---|---|---|
  | 졸병 막사 | 졸병 | 싸고 많다. 물량의 기본 |
  | 궁수 초소 | 궁수 | 뒤에서 화살 일제 사격 |
  | 방패 막사 | 방패병 | 느리고 단단하다. 전선 유지 |
  | 대장간 | 망치 대장 | 비싸다. 한 방에 여럿을 날리는 범위 공격 |

### 3-2. 특성 성좌 (PoE 패시브 트리) — 영혼
- 수십~수백 개 별(노드)이 선으로 이어진 지도. 이미 찍은 별과 이어진 별만 찍을 수 있다.
- 작은 별: +체력%, +공격력%, +생산 속도% 같은 잔잔한 숫자
- 큰 별(**명성**): 성격이 뚜렷한 효과 — "궁수 화살 2발", "졸병 생산 +1명", "처치 시 금화 2배"
- 핵심 별(**쐐기**): 대가가 있는 규칙 변경 — "병사 체력 절반, 생산 수 두 배" 같은 것 (추후)
- 가지가 병종별로 갈라져 있어 빌드 방향을 고르게 된다. 데이터는 `Perks.csv` (도구로 생성), 늘리기 쉽다.

### 3-3. 스펠 — 쿨다운
- Q **유성 낙하**: 커서 위치에 큰 범위 피해. 뭉친 적을 한 번에 날린다.
- E **돌격 함성**: 몇 초간 아군 전체 공격 속도·이동 속도 증가.
- (추후) 얼음 폭풍, 시체 되살리기, 대포 일제 사격…

## 4. 캐릭터와 몬스터 (첫 묶음)

냥코 대전쟁 + 졸라맨 느낌: 굵은 고동 외곽선, 동그란 머리, 점 눈, 멍한 표정. 작게 보여도 실루엣과 색으로 구분되게.

| 편 | 이름 | 특징 |
|---|---|---|
| 아군 | 졸병 | 냄비 투구, 몽둥이. 하얀 몸 |
| 아군 | 궁수 | 초록 두건, 활 |
| 아군 | 방패병 | 큰 나무 방패, 파란 투구 |
| 아군 | 망치 대장 | 덩치 크고 수염, 큰 망치 |
| 적 | 해골 | 기본 졸개. 뼈다귀 몽둥이 |
| 적 | 도깨비 | 작고 빠르다. 빨강 |
| 적 | 뚱보 좀비 | 느리고 체력이 많다. 초록 |
| 적 | 해골 궁수 | 뒤에서 뼈 화살 |
| 적 | 해골 왕 (보스) | 거대, 왕관, 휩쓸기 범위 공격 |

## 5. 조작

- 마우스 왼쪽: 빈 칸 → 고른 병영 짓기 / 지은 병영 → 레벨업
- 1~4: 지을 병영 고르기, Q·E: 스펠 (Q는 커서 위치), T: 특성 성좌 열기
- 휠: 확대·축소, 오른쪽 끌기·WASD·화면 가장자리: 시점 이동, F: 배속, P: 일시정지

## 6. 기술 설계 — 초대용량 유닛

목표: **양 팀 합쳐 2만 이상**이 60fps 근처에서 싸운다.

| 문제 | 해결 |
|---|---|
| 유닛이 액터면 수백 개에서 죽는다 | 유닛은 액터가 아니다. `FYJJHorde`가 **SoA 배열**(위치·속도·체력·대상…)로 들고 있는 순수 C++ 데이터 |
| 서로 찾기 (N²) | 매 틱 **균일 격자**를 계수 정렬로 다시 만든다 (O(N)). 이웃 찾기는 주변 칸만 |
| CPU 한 코어 | 대상 찾기·이동·분리는 `ParallelFor`. 피해는 유닛별 칸에 적고, 적용은 한 번에 순차로 (경쟁 없음) |
| 대상 찾기 비용 | 유닛마다 몇 틱에 한 번만 다시 찾는다 (인덱스로 엇갈리게) |
| 그리기 수만 장 | 모든 유닛을 **아틀라스 한 장 + 삼각형 목록 하나**(`FCanvasTriangleItem`)로 → 드로우 콜 1번. Y 버킷 정렬로 앞뒤 |
| 시체·피가 쌓이면 무거워짐 | 죽는 순간 잠깐 날아가는 연출 후 **바닥 렌더 타깃에 찍어 굽는다**. 몇만 구가 쌓여도 비용 0 |
| 고정 틱 | 시뮬은 1/30초 고정 틱 (배속은 틱을 더 돈다) |
| 아트 반복 | Python(Pillow)으로 아틀라스 PNG를 만들고 게임이 실행 중에 파일에서 읽는다 (밉맵은 게임이 만든다). 에셋 임포트 없음 |

데이터는 YJJ 규칙대로 전부 `Content/YJJWave/Data/*.csv` (수치 `Tuning.csv`, 유닛 `Units.csv`, 병영 `Buildings.csv`, 물결 `Waves.csv`, 특성 `Perks.csv`, 화면 배치 `UILayout.csv`, 글자 `Localization.csv`).
