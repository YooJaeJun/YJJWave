# YJJWave 개발 일지

## 2026-11-22 — 시작: 물량 맞다이의 바탕

- 기획: `Docs/Design.md` (참고작 Here Comes the Horde의 물량 쾌감, 그림·UI는 YJJ식 냥코·졸라맨풍)
- 언리얼 C++ 프로젝트 생성 (UE 5.8.1 소스 엔진). 맵 에셋 없이 HUD 캔버스로 전부 그린다
- 대용량 시뮬 `FYJJHorde`: 유닛 = 배열의 한 칸(SoA), 편별 균일 격자를 매 틱 계수 정렬로 다시 만들고, 대상 찾기·이동·밀어내기는 ParallelFor
- 그리기: 유닛 전부를 아틀라스 한 장 + 캔버스 배치 하나로 (드로우 콜 1번), Y 버킷 정렬. 죽은 몸은 잠깐 날아간 뒤 바닥 렌더 타깃에 피와 함께 구워져 쌓인다 (몇만 구가 쌓여도 비용 0)
- 병영 4종(졸병·궁수·방패·망치 대장), 몬스터 5종(해골·도깨비·뚱보 좀비·해골 궁수·해골 왕 보스), 물결 10레벨 + 무한
- 특성 성좌 65개 별(큰 별 16개), 스펠 2개(유성 낙하·돌격 함성)
- 수치·배치·글자 전부 CSV (Tuning 67, UILayout 136, Localization ko/en)

### 성능 (i5-13400F 10코어/16스레드, RX 7800 XT, 1920x1080 창, 전장 전체가 보이는 확대)

`Tools/RunGame.ps1 -Bench N -Time 20` — 편마다 N마리를 양 끝에 깔고 맞붙임. 유닛이 최대치의 80% 이상 살아 있는 밀집 구간 평균.
